# ADR-003 — Vault file format

## Status

Accepted. This describes format version 1 used by Padlock.

## Decision

Padlock stores a fixed header, a separate MessagePack index, an encrypted entry blob, and a trailing HMAC-SHA256 tag. All multibyte integer fields in the fixed header use little-endian encoding.

| Header offset | Bytes | Field |
| --- | --- | --- |
| 0 | 8 | Magic `PADLOCK\0` |
| 8 | 1 | Format version, currently 1 |
| 9 | 1 | Flags, including recovery enabled |
| 10 | 2 | Reserved |
| 12 | 16 | Argon2 salt |
| 28 | 16 | Vault UUID |
| 44 | 8 | Creation timestamp |
| 52 | 8 | Modification timestamp |
| 60 | 4 | Entry count |
| 64 | 4 | Deleted entry count |
| 68 | 4 | Index length |
| 72 | 4 | Entry blob length |
| 76 | 12 | Argon2 memory in KiB, time cost, and parallelism (three u32 fields). An all-zero tuple selects the legacy fallback. |
| 88 | 16 | Recovery salt |
| 104 | 24 | Recovery nonce |
| 128 | 80 | Recovery ciphertext and tag for KEK + MACKEY |
| 208 | 816 | Reserved |

The index starts at byte 1024. It stores authenticated plaintext metadata, including entry titles and offsets into the encrypted blob. Writers omit the legacy tag index. After the index and entry blob comes the 32-byte tag over the exact preceding bytes. The authenticated open paths verify the tag before decoding the index or using entry offsets. They require the declared lengths and index encoding to consume their sections exactly.

Passphrase open derives KEK and MACKEY from the PDK. Header recovery fields are for optional recovery-key unlock and are zeroed when recovery is disabled. See [ADR-008](ADR-008.md) for the key hierarchy.

## Rationale and consequences

The fixed header makes version and KDF parameter checks possible before scanning the payload. The HMAC requires reading the authenticated bytes and provides integrity for this snapshot. Detecting replay of an older valid snapshot would require an independent trusted reference. The filesystem backend writes a replacement file and renames it into place.

The version byte identifies the whole format. Readers reject unsupported values. Compatibility for future layout changes requires an explicit reader or migration path.

## Implementation

[`vault/format.rs`](../../crates/padlock-core/src/vault/format.rs) defines the offsets and index encoding. [`vault/lifecycle.rs`](../../crates/padlock-core/src/vault/lifecycle.rs) implements authenticated framing and persistence.
